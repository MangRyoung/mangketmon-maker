# 맵툴 로그 정리기

MapTool 채팅 로그(HTML · 텍스트)와 오레마스 방 로그를 읽기 좋은 세션 로그로 정리하는 한 장짜리 웹 페이지. 브라우저 안에서만 돌고, 로그 · 이미지는 그 브라우저(IndexedDB `mtlog`)에 남는다.

바탕은 claude.ai 의 「맵툴 로그 정리기 (슬라임)」 판이다.
- 로그 목록: **폴더**, 줄을 **끌어서 순서 바꾸기 · 폴더에 넣기**(휴대폰은 길게 눌러 끌기), 전체 선택 · 선택 저장(여러 개면 zip) · 선택 삭제
- 캠페인 파일(.cmpgn · .rptok) · assetcache 폴더 · 이름 붙인 이미지로 토큰 이미지 연결, 캠페인별 해제
- 등장인물: 이미지 · 색 · 표시 이름 · GM 서술체 · 숨김
- 스타일: 프리셋 · 색 · 글꼴 · 글자 크기 · 초상 크기 · 줄 간격 · 로그 폭
- 편집 모드: 바로 고치기, 줄 추가 · 속성(화자 · 종류 · 시간) · BGM 넣기 · 삭제, 되돌리기(Ctrl+Z)
- BGM: 음악 파일 · 링크, 스크롤 따라 재생, 저장한 HTML 에서도 재생
- HTML 로 저장 · 텍스트 복사, 파일 끌어 놓기

## 캠페인 로그 보관소 (2026-10-25)
- 로그를 제작기와 같은 Supabase 프로젝트의 `docs` 표(kind `mtlog`, 폴더 · 순서는 `mtlogmeta/tree`)에 올린다. 목록은 제목 · 날짜 · 줄 수만 읽고, 본문은 열 때 받는다.
- 올리기는 「이 브라우저에서 보관소에 올리기」를 켠 브라우저만 한다(기본 꺼짐). 켠 브라우저에서 지운 로그는 보관소에서도 지운다.
- 그림: http(s) 주소는 다, 맵툴 토큰 같은 data: 그림은 로그마다 1.5MB 까지 같이 올린다. BGM 파일은 올리지 않는다.
- 공개 키로 읽고 쓰므로 제작기 시트처럼 링크를 아는 사람은 읽을 수 있다.

## 오레마스 연동
「오레마스 방 불러오기」 칸에 방 링크(`…/oremas/#r=방ID`)나 방 ID 를 넣으면 그 방의 로그를 읽어 온다.
- 대사 · *지문* · 주사위 · 배틀 카드(효과 본문 포함) · 시스템 줄 · 올린 그림을 옮긴다. 휴대폰 문자는 고르면 넣는다. 귓속말은 서버가 공개하지 않아 빠진다.
- 화자 초상은 방의 로스터(트레이너 · 포켓몬) · 관계도 · 스탠딩 그림에서 가져와 메시지마다 잇는다(다른 방의 같은 이름과 섞이지 않는다).
- 오레마스의 「제작기 정리기로」는 제작기 `?tab=log&oremas=방ID` 로 열고, 제작기가 이 페이지(iframe)에 `?oremas=방ID` 를 넘겨 바로 불러온다. 주소의 `?oremas=` 는 한 번 쓰고 지워서, 새로고침해도 같은 로그가 또 생기지 않는다. 같은 방을 다시 부르면 그 로그를 새로 고친다(전 내용은 되돌리기로).
- **오레마스에서 내려받은 파일**(HTML · TXT)도 「로그 파일 추가」 · 끌어 놓기 · 붙여넣기로 넣는다. HTML 은 안에 든 원본 데이터(`<script id="oremas-log">`)로, 그 데이터가 없는 옛 파일은 말풍선 꼴로 읽는다. 패널의 주사위 · 배틀 · 문자 옵션을 따르고, 파일에 든 귓속말은 살린다.
- 읽기 전용. 오레마스와 같은 Supabase 프로젝트의 공개 키로 `om_rooms` · `om_state` · `om_log` 를 읽는다. 50만 줄까지 읽고, 넘으면 알려 준다.

## 원본 보정 (oremas-addon.html)
`src/original.html` 은 그대로 두고, 합친 페이지에서 원본 함수를 덮어써 고친다.
- 화자 판별: 「10:30」 같은 시각의 콜론은 이름 구분으로 읽지 않는다. 표 형식은 이름 칸에서 화자를 찾으면 본문 앞 「…:」 를 자르지 않는다.
- 주사위: `title` 이 있는 span 은 주사위처럼 보일 때(1d20 · « » · = · Rolled …)만 주사위 칩.
- 본문 속 그림과 http(s) 링크를 살린다(그림 · 링크 토큰). 초상은 표의 본문 칸 밖 첫 그림(또는 글자보다 앞의 첫 그림)만. 편집해도 그림이 남는다.
- 정리기가 저장한 HTML 을 다시 넣으면 메시지 · 화자 · 초상 · BGM 을 되살린다.
- 형식 판별은 진짜 태그가 있을 때만 HTML. 파일 인코딩은 UTF-8 → 문서 charset → CP949(EUC-KR) 순.
- 로그를 넣으면 곧바로 저장한다(원본은 0.4초 뒤라 바로 새로고침하면 본문이 비었다).
- 파일 저장: GitHub Pages 에서도 브라우저 내려받기로 저장한다(원본은 claude.ai 저장 기능에 기대 복사만 됐다). 저장할 때 올린 그림(원격 주소)을 파일 안에 담는다.
- 압축 도구 JSZip 을 cdnjs 에서 못 부르면 `vendor/jszip.min.js` 를 쓴다.
- 예전 GitHub 판(저장소 `mtl`)에 넣어 둔 로그 · 화자 설정은 처음 열 때 한 번 옮겨 온다.

## 파일
- `src/original.html` — 정리기 원본(claude.ai 슬라임 판, 그대로 둔다)
- `oremas-addon.html` — 오레마스 연동 + 원본 보정
- `build.py` — 두 파일을 합쳐 `index.html` 을 만든다. 원본이 바뀌면 `src/original.html` 만 갈아 끼우고 `python build.py`.
  합치면서 `<html lang="ko">` 를 붙이고, `<body>` 안에 있던 `<title>` · `<link>` · `<script src>` 를 `<head>` 로 옮기고, 탭 제목의 「(슬라임)」 을 뗀다.
- `vendor/jszip.min.js` — JSZip 3.10.1 (MIT/GPLv3). cdnjs 를 못 쓸 때 대신 쓴다.
- `index.html` — GitHub Pages 가 내보내는 페이지
