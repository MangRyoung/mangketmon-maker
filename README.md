# 망켓몬 제작기 (공용판)

트레이너·포켓몬 시트, DB(기술·특성·포텐셜), 테이블·계산식을 한 페이지에서 다루는 제작기입니다.
GitHub Pages에 올라가는 정적 사이트이고, 데이터는 Supabase 테이블 하나(`docs`)에 저장되어 링크를 아는 사람 모두가 같이 보고 고칩니다.

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 페이지 뼈대 |
| `css/maker.css` | 스타일 |
| `js/maker.js` | 제작기 본체 (시트·DB·계산·공유 저장) |
| `js/store.js` | 공유 DB 어댑터 (Supabase) |
| `js/fx/` | 배틀 자동화 — `fx.js`(구문 해석·실행) · `fx_ui.js`(구문 편집기·생성기) · `readymade.js`(레디메이드 사전 915) · `states.js`(상태 변화 DB). **여기가 원본**이고 오레마스 웹툴은 이 파일들을 `https://mangryoung.github.io/mangketmon-maker/js/fx/` 에서 불러간다. 오레마스 저장소(26차) 기준 사본 + 제작기 「레디메이드」 DB 행을 기본 대신 쓰는 `MKM_RM` 훅. 수정은 **이 폴더에서만** — 오레마스 쪽 `data/states.js`·`data/readymade.js`·`js/engine/fx.js`·`js/fx_ui.js` 는 더 이상 쓰지 않는다 |
| `js/config.js` | Supabase URL · anon 키 (**여기만 고치면 됨**) |
| `data/db.js` | 기본 DB (기술·특성·소지품·포텐셜·테이블). (11-03) 옛 `js/fx.js` · `data/readymade.js` · `data/states_min.js` 는 어디서도 부르지 않아 지웠다 — 레디메이드 · 상태 DB 는 `js/fx/` 가 원본 |
| `supabase/schema.sql` | DB 테이블·권한·실시간 설정 + 그림 저장소(Storage 버킷 `oremas`) SQL |
| `supabase/patch_2026-11-03_제작기.sql` | **변경 이력 · 최근 지운 것** 용 보안 정의자 RPC (`mk_history` · `mk_deleted` · `mk_snapshot`). 한 번 실행해야 제작기의 「이력」 · 「최근 지운 것」이 돈다 (없으면 안내만) |
| `supabase/seed.json`, `supabase/import.mjs` | 옛 세션 노트에서 옮겨 온 데이터와 넣는 스크립트 |

## 처음 설정 (한 번만)

1. **Supabase 프로젝트 만들기** — https://supabase.com 에서 무료 프로젝트 하나를 만든다.
2. **SQL 실행** — 대시보드의 *SQL Editor* 에 `supabase/schema.sql` 내용을 붙여 넣고 Run.
3. **키 넣기** — *Project Settings → API* 의 `Project URL`과 `anon public` 키를 `js/config.js`에 적는다.
4. **옛 데이터 옮기기** (선택) — `node supabase/import.mjs <Project URL> <anon 키>`
5. **GitHub Pages** — 저장소 *Settings → Pages → Deploy from a branch → main / (root)*.

`js/config.js`를 비워 두면 공유 없이 브라우저(localStorage)에만 저장하는 혼자 쓰기 모드로 돈다.

## 데이터 구조

`docs(kind text, id text, data jsonb)` 한 테이블.

| kind | 문서 하나 | data |
|---|---|---|
| `trainers` | 트레이너 | `{ord, data:{...트레이너, pids:[포켓몬 id 순서]}}` |
| `pokemon` | 포켓몬 시트 | `{tid:트레이너 id, data:{...포켓몬}}` |
| `folders` | 폴더 | `{ord, name, priv?, owner?, ownerName?}` — 비공개 폴더도 공유된다 |
| `dbedit` | 기본 DB와 달라진 행 하나 | `{kind, key, row, custom, pos}` 또는 `{kind, key, deleted:true}` |
| `meta` | 설정 묶음마다 하나: `set.tpl` · `set.tags` · `set.ban` · `set.stpl` · `set.oldSock` · `set.soloSock` · `set.ptItems` · `set.pride` · `set.ilock` · `set.rules` | 테이블·계산식 탭의 표. 묶음이 나뉘어 있어 두 사람이 서로 다른 표를 동시에 고쳐도 한쪽이 지워지지 않는다. 예전 한 덩어리 문서 `settings` 는 읽기만 한다 |

**그림**: 스탠딩(트레이너·포켓몬)은 Storage 버킷 `oremas` 에 원본 그대로 올리고 주소만 저장한다(투명 배경 유지). 시트 이미지도 공유 모드에서는 버킷으로 올라가고, 예전 data URL 때문에 문서가 1.5MB 를 넘으면 그 그림을 버킷으로 옮긴 뒤 다시 저장한다. 버킷이 없으면 `supabase/schema.sql` 을 다시 실행한다.

기본 DB(`data/db.js`) 자체는 저장소에 넣지 않고, 거기서 **바뀐 행만** `dbedit`로 저장한다. 그래서 기본 DB를 갱신해도 각자의 수정이 남는다.

## 권한

지금은 「전원 자유」: anon 키로 읽기·쓰기·삭제가 모두 열려 있다(`schema.sql`의 정책).
보기만 허용하거나 비밀번호를 두고 싶으면 정책을 바꾸면 된다. anon 키는 공개되어도 되는 키이고, 실제 권한은 이 정책이 정한다.

## 저장 · 연결 상태 (11-03)

상단의 작은 상태 점이 좁은 화면에서도 보인다: 저장됨 · 저장 대기 · 저장 중 · 다시 시도 중 · 실패 N건 · 읽기 전용 · 연결 끊김 · 이 브라우저. 누르면 실패한 시트 목록과 「다시 시도」 · 「다시 연결」(새로고침 없이 실시간 채널을 다시 붙이거나, 처음 연결에 실패했으면 처음부터 다시).

## 변경 이력 · 되살리기 (11-03)

`docs_history` 는 10-20 보호 패치가 남기던 표(30일 보관 · 5분 안의 거듭 수정은 한 판). `patch_2026-11-03_제작기.sql` 을 실행하면
- 트레이너 · 포켓몬 머리의 **「이력」** → 옛 판 목록 · 「이 판으로 되돌리기」(지금 값을 먼저 이력에 남긴다)
- 파일 ▾ → **「최근 지운 것」** → 30일 안에 지운 트레이너(같이 지운 포켓몬 포함) · 포켓몬 · 폴더 되살리기
- DB 「원본으로 되돌리기」 전에는 백업 JSON 을 먼저 내려받는다.

## 찾기 · 정리 (11-03)

- 캐릭터 탭 위 **이름 검색** — 폴더를 가로질러 트레이너 · 포켓몬 이름이 맞는 카드만.
- DB 행 편집 창의 **「이 행을 쓰는 시트」**(특성 · 소지품 · 포텐셜 · 기술 · 포인트 · 카드) — 누르면 그 시트로. 행 삭제 때 쓰는 시트 수 경고.
- 폴더 머리의 **「점검」** — 그 폴더 트레이너 · 포켓몬의 ⚠ 경고를 한 화면에.
- 포켓몬 카드의 **「옮기기」** — 다른 트레이너로 옮기기 / 복사.
- 파티 검사: 같은 소지품 중복(2 · 3번 칸 포함) · 잠긴 특제 소지품 · 「전체기 C : +4」(띄어 쓴 꼴도) · 특성 이름 띄어쓰기 안내.

## 은열쇠 카드 (11-03)

카드 DB 행에 **「분류」**(12번 칸 `cls` = 열쇠 · 준비 · 증상) · **「덱 제한」**(13번 칸 `deckMax`, 같은 카드 최대 장수 · 비우면 2) 을 더했다. 덱 관리 경고: 열쇠 2 + 준비 6 = 8장 기준 · 같은 카드 초과 · 1장 제한 · 증상까지 10장 (분류를 하나도 안 썼으면 예전처럼 10장 넘을 때만). `js/skcard.js` · `css/skcard.css` 는 웹툴과 같은 파일 — 고치면 양쪽에 같이 넣는다.

## 편의 · 연출 (11-03, 20번 검토)

- 「+ 트레이너」 · 「+ 포켓몬 시트」를 누르면 새 카드로 스크롤하고 이름 칸에 커서가 간다 (터치 화면은 스크롤만).
- 기술 · 특성 검색은 **이름 완전 일치 → 이름 시작 → 이름 포함 → 효과문** 순으로 보인다 (필터는 그대로).
- DB 표의 **머리 칸을 누르면 정렬** (숫자 칸은 숫자로 · 다시 누르면 내림차순 · 한 번 더 누르면 해제). 수정 창에는 **‹ ›** 이전 · 다음 행(표에 보이는 순서, `Ctrl+←` `→`).
- 포켓몬 머리의 「이력」 · 「삭제」와 한 장 요약의 「삭제」는 **「⋯」 메뉴** 안으로. 트레이너 · 포켓몬 · 폴더를 지우면 5초 동안 **「실행 취소」** 토스트가 뜬다 (지운 것을 메모리에 들고 있다가 되살리고, 공유 DB 에도 다시 올라간다).
- 즐겨찾기 레일은 본문(1440px) 바깥 여백에 서고, 1500px 미만에서는 왼쪽 가장자리의 얇은 띠(누르면 펼침, 가고 나면 접힘). 캐릭터 시트 소개 문단은 처음 한 번만 펼쳐 보이고 그 뒤엔 「소개 ▸」(이 브라우저).
- 터치 화면: 단추 최소 40px · 금지어 × · 폼 단추 · 「할인 · 숨김」은 패딩 있는 칩. 모달 머리는 좁은 화면에서 제목 한 줄 + 단추 둘째 줄, 기술 검색 창은 검색 칸이 한 줄을 다 쓴다.
- 연출: 모달 뒤 어둡게 + 흐림 · 한 장 요약 PNG 에 바깥 여백 · 트레이너명 · 날짜 각주 · 테마 배경색 · 꾸미기 없는 트레이너 카드에 옅은 볼 마크(꾸미기 → 무늬 「무늬 없음」으로 끔) · 저장 직후 상태 점 깜빡 + 방금 고친 카드 테두리 반짝 · 타입 분포에서 0 인 타입 막대는 숨기고 「0 인 타입 N개 보기」.

## 백업

파일 ▾ → **백업 저장** 으로 JSON 한 파일에 전부 내려받을 수 있다. 공유 DB가 날아가도 이 파일로 되돌린다.
